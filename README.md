
# 🎀 PinkMagic XO Game

A cute and interactive Tic-Tac-Toe game with a soft pink aesthetic, neon effects, and playful animations.

## ✨ About The Project

I built this project as part of my JavaScript learning journey to practice programming fundamentals by creating an interactive game.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript 

## 🎮 Features

- Interactive XO game board
- Pink and purple themed UI
- Smooth CSS animations and hover effects
- Responsive layout
- Interactive game elements

## 📚 What I Practiced

- DOM manipulation
- Event listeners and event handling
- Conditional statements
- Functions and game logic
- CSS animations and responsive design

## 🚀 Getting Started

1. Clone this repository.
2. Open `index.html` in your browser.
3. Start playing!

## 💗 Purpose

This project is a hands-on JavaScript practice project created to improve my coding skills and learn by building real interactive experiences.
